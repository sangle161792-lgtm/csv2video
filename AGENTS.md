# Agent rules
- Reuse existing components and animations before adding new ones; reusable features belong in `src/library`.
- Episode/story content belongs in YAML, never hard-coded in the engine.
- Generated timeline, SRT, subtitle and lip-sync files are derived artifacts; regenerate rather than editing them.
- Keep the friendly flat Vietnamese-folklore vector art direction. Do not use AI image generation.
- Genuine deterministic, frame-based animation is required; never substitute a slideshow.
- Consider reuse across future episodes for every feature and avoid duplicate animations.
